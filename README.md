# systheme

MVOS 디자인 시스템. 예전 패키지 이름은 `@mvos/design-system` 이다.

`@oobleck/systheme` 은 MVOS 가 자기 화면과 컬렉션 뷰 슬롯에 쓴다. Workstyle 을 대체하지 않는다. 헤드리스 컬렉션 `@oobleck/collection` 위에, 뷰는 이 부품으로 채운다.

구현은 아직 MVOS `packages/design-system` 에 있다.

```json
{
  "@oobleck/systheme": "github:oobleck-cloud/systheme"
}
```
